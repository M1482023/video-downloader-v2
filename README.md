# Video Downloader Actor

Apify Actor להורדת סרטונים מפלטפורמות שונות עם תמיכה בעוגיות לאימות.

## פלטפורמות נתמכות

- YouTube
- Vimeo
- Facebook
- Reddit
- TikTok
- Instagram

## שדות קלט

- **videoUrl** (חובה): כתובת הסרטון להורדה
- **cookies** (אופציונלי): עוגיות בפורמט Netscape לאימות
- **platform** (אופציונלי): פלטפורמה (auto לזיהוי אוטומטי)
- **uploadToDrive** (אופציונלי): האם להעלות ל-Google Drive
- **driveFolderId** (אופציונלי): מזהה תיקייה ב-Google Drive
- **googleClientId** (נדרש להעלאה): Google OAuth Client ID
- **googleClientSecret** (נדרש להעלאה): Google OAuth Client Secret
- **googleRefreshToken** (נדרש להעלאה): Google OAuth Refresh Token

## פורמט עוגיות

העוגיות צריכות להיות בפורמט Netscape (כמו שמייצא הרחבות דפדפן):

```
# Netscape HTTP Cookie File
# This file is generated by the browser extension
.domain.com	TRUE	/	FALSE	1735689600	NAME	VALUE
```

## יצירת קובץ עוגיות

1. התקן הרחבה כמו "Get cookies.txt" בדפדפן
2. התחבר לפלטפורמה הרצויה
3. ייצא את העוגיות והעתק אותן לשדה ה-cookies

## הגדרת Google Drive

כדי להעלות ל-Google Drive, צריך ליצור OAuth credentials:

1. עבור ל-[Google Cloud Console](https://console.cloud.google.com/)
2. צור פרויקט חדש
3. הפעל את "Google Drive API"
4. צור OAuth 2.0 credentials (Desktop app)
5. קבל את ה-Client ID ו-Client Secret
6. השתמש ב-[OAuth Playground](https://developers.google.com/oauthplayground/) כדי לקבל Refresh Token:
   - הגדר את ה-scopes ל-`https://www.googleapis.com/auth/drive.file`
   - הרץ את התהליך וקבל את ה-refresh token

### מציאת Folder ID ב-Google Drive

1. פתח את התיקייה הרצויה ב-Google Drive
2. העתק את ה-ID מה-URL:
   - ה-URL יראה כך: `https://drive.google.com/drive/folders/[FOLDER_ID]`
   - ה-ID הוא החלק אחרי `/folders/`

## דוגמה להרצה עם Google Drive

```json
{
  "videoUrl": "https://www.youtube.com/watch?v=example",
  "cookies": "# Netscape HTTP Cookie File\n...",
  "platform": "auto",
  "uploadToDrive": true,
  "driveFolderId": "YOUR_DRIVE_FOLDER_ID",
  "googleClientId": "YOUR_GOOGLE_CLIENT_ID",
  "googleClientSecret": "YOUR_GOOGLE_CLIENT_SECRET",
  "googleRefreshToken": "YOUR_GOOGLE_REFRESH_TOKEN"
}
```

## פלט

ה-Actor מוציא:
- נתונים ל-Dataset עם פרטי ההורדה
- קובץ ZIP עם הסרטון ב-Key-Value Store
- לוגים מפורטים של כל התהליך

